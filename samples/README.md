# Sample files

Small, real-shaped inputs for trying the API, with the results you should get back.
All are generated by code (`python -m scripts.make_samples`,
`python -m scripts.make_dem_samples`), byte-for-byte reproducibly.

```bash
curl -F "file=@samples/site_survey.kml" http://localhost:8000/api/files/
curl http://localhost:8000/api/files/{id}/measurements/
```

| File | What it exercises | CRS | Features | Expected `summary` |
|---|---|---|---:|---|
| [`site_survey.kml`](site_survey.kml) | KML folders and ExtendedData; a polygon **with a hole**, a LineString, a MultiLineString, a Point, an unsupported `<Model>` | EPSG:4326 | 5 | area **32,408.162 m²**, length **734.589 m**; 3 `MEASURED`, 1 `NOT_APPLICABLE`, 1 `UNSUPPORTED` |
| [`farm_plots.zip`](farm_plots.zip) | A zipped Shapefile bundle with **3 layers** (plots, tracks, wells), attributes | EPSG:4326 | 442 | area **2,086,093.028 m²**, length **4,684.677 m**; 428 `MEASURED`, 14 `NOT_APPLICABLE` |
| [`parcels_utm43n.zip`](parcels_utm43n.zip) | A **projected** Shapefile (UTM 43N) and a NULL shape | EPSG:32643 | 3 | 2 parcels of exactly 100 m × 100 m *in UTM coordinates* measure **9,989.016 m²** and **9,988.989 m²** on the ground (UTM scale error, see the README); the NULL shape is `NOT_APPLICABLE` |
| [`quarry_outlines.kml`](quarry_outlines.kml) | Stockpile outlines and a haul road for the DEMs below | EPSG:4326 | 6 | area **17,547.110 m²**, length **375.417 m**; all `MEASURED` |
| [`quarry_dsm_2026-01.tif`](quarry_dsm_2026-01.tif), [`quarry_dsm_2026-03.tif`](quarry_dsm_2026-03.tif) | Two 0.5 m drone surveys of the same quarry yard, for [DEM volumetrics](../docs/terrain.md) | UTM 43N | — | Volumes with exact analytic answers: see [docs/terrain.md](../docs/terrain.md#accuracy-checked-with-the-sample-surveys) |
